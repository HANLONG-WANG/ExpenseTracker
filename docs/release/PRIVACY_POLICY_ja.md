# プライバシーポリシー

版：1.0　発効日：2026-08-12

本アプリはオンラインアカウントを必要としません。帳簿、添付、設定、操作記録は既定で端末内だけに保存され、SQLCipher、Android Keystore、認証付き暗号化で保護されます。カード保管庫は独立した鍵階層を使い、機密項目の表示、コピー、編集ごとに新しい端末認証が必要です。

オフライン記帳はネットワークに依存しません。利用者が明示的に使う場合だけ、地図スタイル、通貨ペアと日付だけを受け取る為替サービス、Google Drive の `drive.file` 範囲にある暗号化バックアップ、または別途同意した診断送信先へ接続します。広告はなく、データを販売しません。金額、口座、カード、メモ、店舗、場所、添付、バックアップ本文を送信しません。

機能テレメトリとクラッシュ報告は別々に既定オフで、ポリシー同意前は収集・送信しません。有効時も固定列挙と固定 schema だけを使い、インストール ID は 30 日ごとに更新、機能イベントは最長 90 日、クラッシュ報告は最長 180 日保持します。端末内キューは確認・削除でき、無効化すると対応するキューと ID を削除します。

通知、ファイルディレクトリ、位置情報、生体認証、Drive の権限は関連機能を使う時だけ求めます。通常の出力に完全なカード番号、セキュリティコード、保管庫項目は含まれず、座標は既定オフです。バックアップは常に暗号化されます。外部出力と Drive バックアップは「この端末のデータを消去」では削除されず、クラウド削除には別の再認証手順があります。

利用者は診断同意の撤回、端末データ消去、クラウドバックアップの個別削除、アンインストールを選べます。復旧パスワードは再取得できず、アプリやサーバーに迂回手段はありません。Play 公開前に、公開者は最終ポリシー URL とサポート連絡先をストア情報に掲載しなければならず、未設定では公開できません。
