# About and open-source delivery / 关于与开源交付 / このアプリについて

## 简体中文

ExpenseTracker 1.0.0 是原生 Android、离线优先、无广告的加密记账应用。关于页显示实际安装版本、公开源代码入口和主要开源组件许可；每次发布还生成完整 CycloneDX SBOM、机器可读许可证 CSV、HTML 清单和 `THIRD_PARTY_NOTICES.txt`。最终源代码仓库 URL 须由发布者确认后才能提交商店。

## 日本語

ExpenseTracker 1.0.0 は Android ネイティブ、オフライン優先、広告なしの暗号化会計アプリです。このアプリについて画面には実際のインストール版、公開ソースへの入口、主要 OSS ライセンスを表示します。各公開版は完全な CycloneDX SBOM、機械可読ライセンス CSV、HTML 一覧、`THIRD_PARTY_NOTICES.txt` も生成します。最終ソースリポジトリ URL は公開者の確認後にストアへ提出します。

## English

ExpenseTracker 1.0.0 is a native Android, offline-first, ad-free encrypted ledger. About displays the installed version, public source entry, and major open-source licenses. Every release also generates a complete CycloneDX SBOM, machine-readable license CSV, HTML inventory, and `THIRD_PARTY_NOTICES.txt`. The publisher must confirm the final source repository URL before store submission.
