# ExpenseTracker 1.0.0 release notes

## 简体中文

- 完整的离线加密记账、账户、信用卡、分期、贷款、预算、目标、项目与互请流程。
- CSV/XLSX 原子导入，CSV/XLSX/PDF/图片导出，以及本地/Google Drive 始终加密备份与安全恢复。
- 三语、TalkBack、自适应布局、桌面小组件、严格保险库认证和可审计隐私诊断。
- 目标规模覆盖 50 万当前交易、200 万历史变动、10 万行导入和数十 GiB 流式操作。

## 日本語

- オフライン暗号化記帳、口座、クレジットカード、分割、ローン、予算、目標、プロジェクト、立替精算を一通り実装。
- CSV/XLSX の原子的インポート、CSV/XLSX/PDF/画像出力、ローカル/Google Drive の常時暗号化バックアップと安全な復元。
- 3 言語、TalkBack、適応レイアウト、ホーム画面ウィジェット、厳格な保管庫認証、監査可能なプライバシー診断。
- 50 万件の現行取引、200 万件の履歴変更、10 万行インポート、数十 GiB のストリーム処理を対象規模で検証。

## English

- Complete offline encrypted recording, accounts, credit cards, installments, loans, budgets, goals, projects, and shared-expense settlement.
- Atomic CSV/XLSX import; CSV/XLSX/PDF/image export; always-encrypted local and Google Drive backup with safe restore.
- Three languages, TalkBack, adaptive layouts, home-screen widgets, strict Vault authentication, and auditable privacy diagnostics.
- Target-scale validation covers 500,000 current transactions, two million historical changes, 100,000-row imports, and tens-of-GiB streams.
