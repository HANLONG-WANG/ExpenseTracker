# 余量 · 三套独立主题设计稿

入口：[index.html](index.html)。字体与图形已随项目提供，无在线素材依赖。通过本地 HTTP 预览服务加载字体和同步对照功能，在项目根目录运行：

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

打开 `http://127.0.0.1:4173/design/index.html`。对比页可并列查看三套主题，或选择单版聚焦。「同步查看」可同时切换三版页面、首次设置、换汇、外币核对、活动预算、自定义分析、分类选择、条目详情、小票工作台及附件预览。手机内独立滚动，单版适配手机宽度。

三套主题拥有独立的版式、字体和组件：杂志的编辑页与编号目录、手账的纸页与勾选清单、小物的口袋/小票/实体卡片。输入、菜单、日期选择、弹窗、提示和空状态也分别设计。仅业务与数据共用。字体角色和许可说明见 [字体说明](fonts/README.md)。

## 可以顺着体验的流程

1. 在日常账本里确认房租付款，返回首页：预算余额与预留同步变化，可支配金额不重复扣减。
2. 切换兴趣账本记一笔，再切回日常：两个账本的金额互不影响。
3. 在记账面板关联一个活动、填 ¥6,000，展开请客并选择两位朋友：包括自己在内默认各 ¥2,000，自用不计请客贡献。
4. 找九月的「無印良品」消费，记录十月退款：九月净消费减少，十月预算不增加，账户资金按到账更新。
5. 核对页载入演示流水：未匹配的 ¥1,280 可补记，补记确认后重新匹配。转账样例展示一侧已核对、另一侧未核对。
6. 信用卡规则页填写年率、月还款和分期表，保存后试算；例如手续费表格式 `3:2.01,6:4.02`，这些数字仅是用户可填写的示例，不是任何机构预设。

## 新一轮可以体验的流程

1. 顶部「先选分类」对照三种独立分类页；选分类进入记账，重选时保留已经填写的内容。收入没有示例分类时可直接创建；新账本不预建分类。
2. 顶部「详情 / 编辑」打开「ライフ」示例：点编辑，更改内容并保存会更新原条目，取消则保留原条目。附件区可实际选取本地文件，文件仅用于本次预览。
3. 详情里的购物袋图片可放大，购物备注音频提供播放/进度条，PDF 只展示外部应用交接；不在应用内预览 PDF 或视频。
4. 「小票工作台」全选待识别小票，预览导出结构，下载明确标注的[示例 ZIP](examples/yohaku-receipts-sample.zip)，再查看「已导出 · 待回填」状态。示例包是固定内容，不是对用户上传图片的生产打包实现。
5. 导入[商品明细示例](examples/receipt-items-sample.json)或点击预览示例，确认后将五项商品关联至原 ¥8,500 记录；原金额不变。可查看金额不一致状态、重复回填的替换确认，并在原记录编辑页修改商品明细。

小票商品回填采用独立类型 `yohaku.receipt-items`，通过 `book_id`、`record_id`、`receipt_id` 关联；包含币种与名称/数量/单位/单价/行金额。与下面的银行流水核对格式分开，不创建新的记账，不提供 OCR。示例图片和音频都是虚构素材。

## 第五轮页面打磨

1. 「首次设置」：账本/本位币/预算 → 资金账户原币期初余额 → 信用卡或借款已有欠款 → 检查。可跳过账户；体验数据需主动添加。完成后新账本没有分类、消费和分析偏好。
2. 「外币记账」：示例为 USD 原消费、JPY 信用卡入账，区分预计换算与已确认实际金额；小票商品以原消费币比较，不把两种币种直接相加。
3. 「换汇」：两端账户和实际扣款/净到账金额均可填，展示参考及综合到账汇率；手续费区分已含转出、已含转入、另付。可查看计划、在途和已到账状态，以及双端详情。
4. 「汇率核对」：USD 100 / 预计 JPY 15,000 / 账单 JPY 15,230；点击金额确认查看原条目与预算影响，确认才修改。保留差异仍是预计金额。
5. 「活动预算 / 互请」：活动总/分类预算、月预算排除开关、主动资金预留分别表达。多人均分包含自己和付款人，可自定义；只比较你和每位朋友在本活动的份额。
6. 「自定义分析」：选择模块、调整先后、以首项为重点。应用只保存到当前账本。未选择时可以主动看示例，不替用户设定重点。
7. 「账户」：新增人民币/美元资金账户和人民币固定计划借款，查看原币余额、手动已知还款及规则未配置状态；日本循环借款显示未填写额度状态，额度不作为资金。

这轮仍以布局、组件与演示状态为主，所有汇率、计划和时间线均为虚构，不能作为正式计算依据。

## 流水核对导入格式

使用 JSON，日期 `YYYY-MM-DD`，金额为该账户原币的正数（日元零位小数，人民币/美元两位小数），资金方向 `out` 或 `in`。

```json
{
  "version": 1,
  "book": "daily",
  "account": "pp",
  "from": "2026-10-01",
  "to": "2026-10-12",
  "complete": true,
  "rows": [
    {"id": "external-1", "date": "2026-10-12", "amount": 680,
     "direction": "out", "summary": "喫茶と余白"}
  ]
}
```

本稿的账本与账户标识来自演示数据；正式文件格式还可继续讨论。导入只建立核对资料，不自动新增、改动或删除记账。可在导入页下载当前格式示例。

## 演示边界

- HTML 仅为高保真 UI demo，后续以页面、弹窗、菜单、视觉状态及示例交互为重点，不要求真实业务逻辑。现有数据联动和试算只辅助展示；正式安卓应用的准确计算与数据处理另行实现。
- 日期固定为 2026-10-12。金额、机构名称及还款日期全部是虚构演示，不代表机构规则。
- 账本与交易修改只保留在当前页面，刷新重置。主题选择会记住；没有正式数据存储、备份或同步。
- 已实现页面内预算、消费分析、账户余额、活动、请客和核对反馈的联动。
- 金融试算是填写通用规则后的演示模型；完整逐日余额、首次计费、节假日、计费版本和额度恢复尚未实现。高级设置目前呈现配置结构。
- 位置与权限状态为演示，不读取电脑真实位置。
- 应用正式名称「余量 / ヨハク / YOHAKU」。这是可继续打磨的高保真产品设计稿，尚非正式安卓应用。

## 第六轮规格回查补全

顶部新增「重要事项」「提醒设置」「外币退款」「记录借入」「既有分期」「异常与空状态」。

- 记账表单上方可切账本：保留草稿/放弃/继续编辑；草稿归属原账本。切回后首页继续草稿。表单内切主题保留金额、分类与附件。
- 退款同时填写商户原币退款、账户实际到账、本位币冲减额和到账状态；预览原消费月净额。USD 100 / JPY 15,000 的样例实际退回 JPY 14,800，可保留 JPY 200 净支出。
- 借款详情有逐笔合同、实际净到账/费用与手动逐月计划；还款表单支持部分/提前/结清、直接跨币种本金及平台收到额、清偿待确认、关联已有换汇。操作只记录资料。
- 信用卡账单可选还款月份，填本金/费用/总额；分期页面可补已有计划，规则可填独立子额度与变更截止。
- 活动月预算排除变更先预览历史月份影响；预留可在记账使用或手动释放。活动内互请支持比例输入与原记录修正。
- 分析可筛时间、分类、商户，查看原消费/退款和变化原因、逐月趋势。分类管理可设置一级/二级常用快捷入口。
- 首页有剩余天数、预留后日均可花、今日净消费；提醒只保留重要类型。状态预览集中展示资料不足、未授权、加载/失败、媒体无法打开等处理入口。
